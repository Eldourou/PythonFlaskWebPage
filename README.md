<b>Εβδομάδα 10 (27/5/2026)
Ενίσχυση Ασφάλειας Διαχειριστικού Περιβάλλοντος και Αποτροπή Κακόβουλων Επιθέσεων</b>

1. Ασφάλεια Συνεδριών (Session Cookies) Για την αποτροπή υποκλοπής των στοιχείων σύνδεσης (session hijacking) μέσω επιθέσεων XSS (Cross-Site Scripting), παραμετροποιήθηκαν τα cookies της εφαρμογής. Ενεργοποιήθηκαν οι ρυθμίσεις HttpOnly ώστε να μην είναι προσβάσιμα μέσω σεναρίων JavaScript, καθώς και η ιδιότητα Secure για την αποκλειστική μετάδοσή τους μέσω κρυπτογραφημένων συνδέσεων (HTTPS). Επιπρόσθετα, εφαρμόστηκε η πολιτική SameSite = Lax για περιορισμό της αποστολής τους από τρίτους ιστότοπους.
2. Προστασία έναντι CSRF (Cross-Site Request Forgery) Με στόχο την αποτροπή πλαστογράφησης αιτημάτων, θωρακίστηκαν όλες οι φόρμες της εφαρμογής (σύνδεσης διαχειριστή, επικοινωνίας και προσφορών) με τη χρήση της βιβλιοθήκης Flask-WTF. Πλέον, το σύστημα ελέγχει την ύπαρξη ενός μοναδικού, κρυφού κρυπτογραφικού token σε κάθε POST request, διασφαλίζοντας ότι το αίτημα προέρχεται αποκλειστικά από τον ίδιο τον ιστότοπο και όχι από κακόβουλους τρίτους.
3. Αποτροπή Επιθέσεων Brute-Force (Rate Limiting) Για την προστασία του διαχειριστικού περιβάλλοντος από αυτοματοποιημένες επιθέσεις δοκιμής κωδικών (brute-force attacks), υλοποιήθηκε μηχανισμός Rate Limiting μέσω της βιβλιοθήκης Flask-Limiter. Εφαρμόστηκε αυστηρός περιορισμός ρυθμού στο endpoint της σύνδεσης (π.χ. μέγιστο όριο 5 προσπαθειών ανά λεπτό), μπλοκάροντας αυτόματα και προσωρινά τις IP διευθύνσεις που παρουσιάζουν ύποπτη συμπεριφορά.

<b>Εβδομάδα 12 (10/6/2026)
Εφαρμογή SEO - Schema.org</b>
Όνομα σπουδαστή: Ελένη Δούρου
Πρόοδος που σημειώθηκε στην εργασία: 

Εφάρμοσα τους ακόλουθους κανόνες SEO:

### 1. Ονοματοδοσία Αρχείου
Τα αρχεία μου έχουν περιγραφική ονοματοδοσία στα αγγλικά (`index.html`, `company.html`, `services.html`, `contact.html`, `admin.html`).

### 2. Title Tag & 3. Meta Description
Στο `base.html` υπάρχουν δυναμικά blocks:
```html
<title>{% block title %}{% endblock %} | Γεντίκης Λεωνίδας</title>
<meta name="description" content="{% block description %}Εξειδικευμένες υδραυλικές υπηρεσίες στην Κηφισιά από το 1999.{% endblock %}">
```
**(Λέξεις-Κλειδιά):** Στα titles και τα descriptions των σελίδων πρόσθεσα δυνατές λέξεις-κλειδιά όπως «Υδραυλικός Κηφισιά», «Αποφράξεις», «Φυσικό Αέριο».

### 4. Responsive Σχεδίαση
Υπάρχει στο `base.html` η απαραίτητη γραμμή:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
Επιπλέον, στο `style1.css` έχω βάλει `@media (max-width: 768px)` για να προσαρμόζεται το μενού και το λογότυπο στα κινητά.

### 5. Σωστή Δομή Επικεφαλίδων
Κάθε σελίδα έχει μόνο ένα `<h1>`.

### 6. Semantic HTML
Στο `base.html` χρησιμοποιώ `<header>`, `<nav>`, `<main>`, και `<footer>`. 
Στα άλλα αρχεία html χρησιμοποιώ `<section>`, `<article>`, `<figure>` και `<figcaption>`.

### 7. Εικόνες με Alt
Όλες οι εικόνες έχουν περιγραφικά `alt` attributes.

### 8. Καθαρά URL (Clean URLs)
Υπάρχει ένα σχόλιο στην κορυφή κάθε αρχείου που να δηλώνει το ιδανικό URL.

### 9. Δήλωση Γλώσσας & Charset
Υπάρχουν στην κορυφή του `base.html`:
```html
<html lang="el">
<meta charset="UTF-8">
```

### 10. Canonical Tag
Υπάρχει στην κορυφή του `base.html`: 
```html
<link rel="canonical" href="[https://www.gentikis.gr](https://www.gentikis.gr){{ request.path }}">
```
Αυτό παράγει αυτόματα το σωστό canonical URL για κάθε σελίδα (π.χ. `https://www.gentikis.gr/services` όταν ο χρήστης είναι στις υπηρεσίες).

### 11. Schema.org
Πρόσθεσα το Schema script μέσα στο `<head>` του κεντρικού αρχείου `base.html`.

### Τι είναι το Schema.org και γιατί χρειάζεται;
Οι μηχανές αναζήτησης (όπως η Google) διαβάζουν το κείμενο της σελίδας σου, αλλά δεν μπορούν πάντα να καταλάβουν με βεβαιότητα τι σημαίνει. Για παράδειγμα, βλέπουν ένα όνομα και ένα τηλέφωνο, αλλά δεν ξέρουν αν πρόκειται για εταιρεία, για κάποιο άρθρο ή για έναν τοπικό επαγγελματία. 

Με το Schema.org, προσθέτεις έναν κρυφό κώδικα στον οποίο λες ξεκάθαρα στην Google: «Αυτός ο ιστότοπος αντιπροσωπεύει μια τοπική επιχείρηση υδραυλικών εγκαταστάσεων (Plumber), με αυτή την ονομασία, αυτή τη διεύθυνση και αυτά τα τηλέφωνα επικοινωνίας». Αυτό βοηθάει την επιχείρηση να εμφανίζεται στα τοπικά αποτελέσματα (Google Maps / Local Pack) και να αποκτά καλύτερη κατάταξη.

Το "priceRange": "$" είναι μια ιδιότητα που χρησιμοποιεί το Schema.org και την οποία ζητάει συνήθως η Google για τις τοπικές επιχειρήσεις.
Ουσιαστικά, δηλώνει το σχετικό επίπεδο τιμών της επιχείρησης σε σύγκριση με τον μέσο όρο της αγοράς. Δεν αναφέρεται σε συγκεκριμένα ποσά, αλλά λειτουργεί ως ένας γενικός δείκτης κόστους.
Η κλίμακα που χρησιμοποιείται διεθνώς είναι η εξής:
•	$ : Οικονομικό / Πολύ προσιτό
•	$$ : Μεσαίες / Λογικές τιμές αγοράς (Μέση κατηγορία)
•	$$$ : Ακριβό / Premium υπηρεσίες
•	$$$$ : Πολύ ακριβό / Πολυτελείας
